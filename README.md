# LevelUp Scuola — prototipo 0.1

Prima versione giocabile per la prima e seconda superiore, con grafica street art/fantascientifica e modalità singolo giocatore.

## Prova
1. Apri `index.html` in un browser.
2. Per testare la PWA, abilita GitHub Pages dalle impostazioni del repository (Settings → Pages → Deploy from a branch → main → /(root)).
3. Apri il sito da Chrome su Android. Il service worker funziona solo in HTTPS o localhost.

## Funzioni
- Dashboard XP, monete, livello, serie e record.
- Quiz a cinque domande per chimica, scienze, geografia, inglese, matematica, storia e fisica.
- Spiegazione dopo ogni risposta, premi e distintivi.
- Percorso per prima e seconda superiore.
- Salvataggio locale nel browser; service worker per cache di base.

## Limiti
Questo è un prototipo dimostrativo. I contenuti non costituiscono un programma completo né una certificazione ministeriale. Non ci sono account, sincronizzazione cloud o classifiche online. Le icone PWA definitive sono da aggiungere.
